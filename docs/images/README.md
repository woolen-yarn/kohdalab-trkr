# UI screenshots

The repository screenshots are isolated documentation captures from the
synthetic/demo launcher. They use generated data and an application-owned demo
profile; no instrument, user profile path, token, or real measurement is shown.

- `gui-trkr.png` — TRKR measurement shell with the left device/config rail,
  central plots, and the collapsible right data/log rail. Refreshed from the
  2026-10-29 device-free smoke capture; the visible config path is the
  anonymized app-owned `~/.kohdalab/trkr/config.json`.
- `gui-srkr-2d.png` — SRKR 2D plot layout and independent axis controls,
  refreshed from the same isolated synthetic capture.
