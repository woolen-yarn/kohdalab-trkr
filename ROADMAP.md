# Roadmap

- Commission full physical scans on each laboratory apparatus after operator checks.
- Complete the SignPath Foundation application and activate approved signing.
- Add Apple Developer ID signing/notarization if a project account is provided.

## 日本語

- 操作者の確認後、各実験装置で実機の全スキャンを立ち上げ・検証する。
- SignPath Foundationへの申請を完了し、承認された署名を有効にする。
- プロジェクト用アカウントが用意された場合、Apple Developer ID署名と公証を追加する。
